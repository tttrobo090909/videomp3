# 영상MP3 by 피피 🎵

유튜브 링크 또는 스마트폰 동영상 파일에서 오디오를 추출하여 MP3 파일로 저장하는 안드로이드 앱입니다.

## 주요 기능
- **유튜브 링크 MP3 추출:** 유튜브 영상 링크를 붙여넣으면 고음질(320kbps) MP3로 즉시 추출
- **유튜브 제목 자동 적용:** 다운로드 시 영상의 제목이 자동으로 깔끔한 파일명으로 적용
- **로컬 동영상 오디오 추출:** 폰에 저장된 동영상 파일에서 초고속 무손실 오디오 분리
- **자동 저장:** 스마트폰 `Music/영상MP3` 폴더에 자동 생성 및 영구 보관
- **인앱 플레이어 & 삼성 뮤직 연동:** 앱 내에서 바로 재생하거나 '삼성 뮤직'으로 연동 청취
- **공유 및 관리:** 카카오톡 등 외부 공유 및 간편 삭제 기능 지원
